# Chirpy

A simple http server built around the [Learn HTTP Servers in Go](https://www.boot.dev/courses/learn-http-servers-golang) course from [Boot.dev](https://boot.dev)

## setting up

Copy [.env.example](https://github.com/libresoul/chirpy/blob/main/.env.example) to .env and set your environment variables accordingly

Start the http server
```bash
go build
./chirpy
```
